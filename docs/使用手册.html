Graderley 使用手册

网址 graderley.com。一个网页，老师布置作业、批改录音和作文、排课、记录课程进度；学生在手机或电脑上完成作业、看反馈、约课、打卡。不用装 App，Chrome、Edge、Safari 都能用。

开始使用

老师登录

  1. 打开 graderley.com，进入 老师登录，用手机号注册（带国家码，如 +86 开头）。
  2. 新账号显示「待激活」，向管理员索取激活码，输入后即可使用。激活码与注册手机号绑定，只能激活这一个账号。
  3. 以后用同一个手机号 + 密码登录。登录时手机号格式要和注册时一致。

先看示例学生

新账号的工作台里已经有一位「示例学生」：一份待批改的口语作业（含录音和转写）、一份已批改的写作作业、一节上过的课和一个每日任务，每个页面都有内容可以点开看。熟悉之后在首页顶部点 移除示例学生 一键清掉。

把学生加进来

在 学生档案 → 学生注册 复制你的专属注册链接发给学生。学生打开链接，用手机号注册，注册完直接进入你的班级，不用手动添加。学生账号免费。

时区

平台按每个人所在时区显示时间：你看到的是你的本地时间，学生看到的是学生的本地时间。排课和课程进度里会在必要处标注对方时区。

工作台首页

登录后左侧是固定边栏，右侧是内容区。边栏结构：

工作台首页：本周课程安排、待办事项、最新动态
作业布置口语 · 写作 · 每日任务
作业批改口语 · 写作（各含「学生情况」和「批改作业」）
排课管理排课 · 课程进度
学生档案总览 · 学生注册
底部本月用量、退出登录
课程安排

接下来要上的课，按天分组。已在课程进度里填了板块的课，会带上口语/听力等标签。点「去排课」进入排课页。

待办事项

你自己的工作清单。输入内容、可选时间，添加；勾选完成、编辑、删除。过期未完成的时间显示为红色。

最新动态

近 30 天学生的动态：交作业、约课、取消、新注册。平台公告也显示在这里的最上方。点「去批改」直接进入批改页。

作业布置

作业布置 → 口语 或 写作

进入后默认是 发布新作业；顶部可切换到 历史发布作业。

发布新作业（口语）

  1. 左侧「已发布作业」列表可按名称搜索、滚动；点一条即载入编辑，或点 新建空白作业。
  2. 填写作业标题（口语作业会根据所选话题自动建议标题）、截止日期、训练说明。
  3. 分配学生 下拉里勾选学生；一个都不勾表示对所有学生可见。选了学生后，下方「该学生之前发布过的话题」会列出他做过的话题，避免重复。
  4. Part 1 题库：输入关键词筛选话题，点选后 添加到 Part 1（追加）或 替换 Part 1。已布置给该学生的话题会标「已布置过」。题库默认只列当季（9–12 月）话题，勾选「含往期话题」可看到往期。
  5. Part 2 & 3 题库：同样筛选后 应用到 Part 2 & 3，题卡和 Part 3 问题会自动填入，都可以手动改。
  6. 点 发布为新作业。再次点开这份作业修改后可以「保存」覆盖。

发布新作业（写作）

写作作业由 Task 1、Task 2 组成，可只留其一。每个任务有标题、字数要求、题目要求；Task 1 可选类型（折线图、柱状图、饼图、表格、流程图、地图）并上传图表图片；Task 2 可选类型（单边观点、双边讨论、原因分析+观点、现状分析+观点）和主题。

历史发布作业

列出所有已发布作业，可打开修改，或从列表隐藏（学生已交的内容会保留）。

每日任务

作业布置 → 每日任务

顶部切换 任务布置 / 完成情况。

  • 任务布置：填标题、类型（词汇、口语话题、听力、阅读、写作、综合）、开始与结束日期、任务说明，勾选学生，点 创建每日任务。学生在这段日期内每天都要打卡一次。
  • 完成情况：左侧学生列表显示「当日已完成 / 当日任务数」，点学生查看每项任务的打卡日历，可编辑或删除任务。

作业批改

作业批改 → 口语 或 写作

顶部切换 学生情况 / 批改作业。

学生情况

左侧学生列表标注批改进度（已批 / 已交）。点开一个学生：作业历史（已批改 已提交 已发布）、给该学生发布作业的快捷入口、分数曲线；口语板块还有「自主口语练习」——学生自己从话题板提交的练习，在这里逐题点评打分。点作业历史里的某次提交会直接跳到批改。

批改作业（口语）

  1. 用 按作业查找 或 按学生查找 找到提交，点开。
  2. 每题可播放录音，点 生成转写 得到文字稿；直接在转写上修改，选中一段文字点 添加批注，然后 保存转写修改。发布后学生会看到你的增删痕迹（绿色新增、红色删除线）和批注。
  3. 可在本题下 录制示范回答，学生发布后可播放参考。
  4. 填写每题点评；AI 反馈草稿 可先生成一版评分和总评，再自己修改。
  5. 在评分区填各项分数与总评，点 发布批改。学生端随即可见，作业状态变为「已批改」。

批改作业（写作）

打开一份作文提交后进入审阅：左侧是学生原文和题目，右侧直接在学生作文上修改，下方实时显示修订痕迹；选中文字点 添加批注；每题填总点评，保存后同样在评分区打分、发布。

删除

批改页里可删除一份提交（含全部录音），不可恢复；作业本身只能「隐藏」，不会删掉学生已交的内容。

排课

排课管理 → 排课

添加可预约时间

在周历上先点开始时间、再点结束时间（或在右侧手动调整），点「添加可预约时间」。学生会按自己的时区看到这些绿色时段并自助预约。

直接新增课程

为某个学生排一节课，不用等他预约：选学生、时间、类型（试课 / 1 小时 / 2 小时）。填过去的时间即为补录已上过的课，会计入已上课时。

课程预约请求

学生发起的预约先是「待确认」，点「确认」即排定；「取消」可直接取消，建议的新时间为可选项，填了会一并告知学生。

已结束课程

上过的课在下方列出，可「删除」错误记录（同时从已上课时中扣除）。

每节正式课预留 1.5 小时（2 小时课预留 2.5 小时），预留时段对其他学生显示为已占用。

课程进度

排课管理 → 课程进度

每个学生一张课程表，一行一节课，按时间排序，序号即第几课：

列内容
时间你的本地时间；学生时区不同时小字标注学生当地时间
板块口语 / 听力 / 阅读 / 写作 / 模考 / 试课，可多选
课题这节课讲了什么（多行）
课件用的 PPT 或材料名
作业 / 备注课后作业或备注
完成上完后打勾
  • 行来自排课（已确认的课和补录的课）；还没上的课排在后面灰显。
  • 编辑 在行内展开填写；删除 会把这节课从课程表一并移除。
  • 新建课程：填时间、类型、板块、课题等。若该学生在这个时间已有课（学生约的或你排的），内容会写到那节课上，不会重复创建；没有则自动加入课程表。和别的学生撞时间会提示冲突。

学生档案

学生档案 → 总览

顶部是全班统计：在读学生、总课程数、总上课时数、各科课时。下方每个学生一张卡片，折叠时显示姓名、学习时长、总上课时数；点开显示账号、已上课时（含课节数）、各科课时、当前水平（口语 / 写作最新分）、距离考试、课程计划、下次上课，以及 查看学生情况 和 编辑。已停课学生单独一块列在下方。

编辑学生信息

  • 考试时间：选日期或点「N 个月后」快速设置；勾「日期已确定」表示已报名，不勾则按预估显示倒计时。学生自己也能在学生主页改。
  • 已上课时：默认按课程表自动统计（已确认且已过去的课，1 小时课 = 1 课时）；留空即自动，填数字则以填的为准。
  • 上课状态：在读 / 已停课。停课的学生不再出现在布置作业、批改等页面的名单里，数据全部保留，随时可改回。
  • 课程计划：如 全科、单科口语、全程陪跑 等；学生主页据此只显示相关板块的曲线。

姓名、手机号、注册日期来自学生账号，这里只读。

用量与语言

  • 边栏底部 本月用量 显示录音转写分钟数、AI 批改次数、存储空间，每月重置。
  • 右上角 English / 中文 一键切换整站界面语言，老师端、学生端各自记住自己的选择。你手动输入的内容（作业标题、点评等）不会被翻译。

学生主页

学生登录后同样是左侧边栏：学生主页、作业（口语 · 写作 · 每日任务）、课程预约。主页内容：

下次上课

最近一节已确认或待确认的课，按学生本地时间显示。

距离考试还有

倒计时，学生可自己设定或修改考试日期；下面显示课程计划。

每日打卡

今天要完成的每日任务，勾选即打卡；点开可看全部任务和日历。

最近通知

平台公告、新作业、已发布的反馈，点击直达。

再往下是 口语学习情况（分数曲线）与 口语过题情况（Part 1 / Part 2 话题板：绿勾为已练过；点未练的话题可直接开始「自主练习」录音提交给老师；往期练过的话题单独列在底部），以及 写作学习情况。显示哪些板块取决于课程计划（单科口语只显示口语）。

完成作业

作业 → 口语 或 写作

口语

  1. 打开最新作业。Part 1、Part 3 逐题录音，Part 2 录一段完整回答；每题可 开始录音 / 停止、删除 重录，或 上传音频。
  2. 保存已录内容 把录音存进账号，下次打开还在，老师看不到。
  3. 全部完成后点 提交给老师，老师才能看到并批改。

写作

在任务框内写作，可先 保存写作 分次完成，最后 提交给老师。Task 1 的图表在题目下方。

查看反馈

老师发布后，作业状态变为 已批改：能看到各项分数、总评、每题点评，转写上老师的修改痕迹和批注，以及老师的示范回答（可播放）。历史作业里能回看所有提交。

右侧「索引」面板可在页面各部分之间快速跳转。

预约上课

课程预约 → 预约上课

  1. 周历里绿色为可预约时段，灰色为已被约走。点一个开始时间，选课程类型（试课、1 小时、2 小时）。
  2. 一次最多选 5 节，点 提交预约，状态为「待确认」，老师确认后变为「已确认」。
  3. 需要取消时在「即将开始的课程」里点 取消预约；须在开课前至少 4 小时。老师取消时如附了建议时间，会显示在该课下方。

常见问题

现象处理
登录提示「手机号或密码不正确」手机号要和注册时格式一致（含 +86 等国家码）；确认选对了「老师登录 / 学生登录」。
录音按钮没反应浏览器需要允许麦克风权限；请用 Chrome、Edge 或 Safari，微信内置浏览器不支持录音。
录音保存了但老师看不到「保存」只存在学生自己账号里，需再点「提交给老师」。
学生在名单里找不到检查学生档案里是否被设为「已停课」；或学生尚未通过你的注册链接注册。
已上课时和实际不符在课程进度里补录或删除课程；或在学生档案「编辑」里直接填写课时数。
话题板上练过的话题不见了往期题库的话题在话题板底部「往期话题（已练过）」一栏；布置作业时勾选「含往期话题」可选到。
界面显示英文右上角点「中文」切回。
